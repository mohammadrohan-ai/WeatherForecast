# 🌦️ Weather Forecast

A Python CLI application that uses the OpenWeather API to fetch real-time weather information for a city.

## ✨ Features

- 🌍 Search by city and country
- 🌡️ Temperature and feels-like temperature
- ☁️ Weather conditions
- 💧 Humidity
- 💨 Wind speed
- 🔽 Minimum & maximum temperature
- ⚠️ Input and API error handling
- 🔐 Secure API key storage with `.env`

## 🛠️ Built With

- 🐍 Python
- 🌐 OpenWeather API
- 📡 Requests
- 🔐 python-dotenv

## 🚀 Setup

Install the dependencies:

pip install -r requirements.txt

Create a `.env` file:

OPENWEATHER_API_KEY=your_api_key_here

Run the program:

python main.py
